# Code of Conduct

diorama follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Report concerns through the channels listed in that document. For this repository, you may
also reach maintainers via [GitHub issues](https://github.com/geoffsee/diorama/issues)
when a private channel is not required.

We expect participants to ask questions, give specific and useful feedback, receive it
openly, and treat others with respect. Harassment and personal attacks are not tolerated.
